# .github

Organization-wide default community health files for [Mesoblock](https://github.com/mesoblock).

Repositories under this organization that don't define their own copy of `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SUPPORT.md`, or `SECURITY.md` will inherit these by default (this is standard GitHub behavior for a repo named exactly `.github` at the org level).

`profile/README.md` in this repo is also what renders on the [organization's public profile page](https://github.com/mesoblock).
