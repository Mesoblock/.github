# Support

Mesoblock is early-stage and mostly solo-maintained, so please bear with response times.

## Have a question?

Open a [GitHub Discussion](https://github.com/mesoblock/mesoblock/discussions) on the main repository (enable Discussions on that repo if it isn't already).

## Found a bug?

Open an [issue](https://github.com/mesoblock/mesoblock/issues) with:

- What you expected to happen
- What actually happened
- Steps to reproduce
- Your environment (browser, OS, if relevant)

## Found a security issue?

**Do not open a public issue.** See [SECURITY.md](./SECURITY.md) for private disclosure instructions.

## Want to contribute?

See [CONTRIBUTING.md](./CONTRIBUTING.md).
